# Migrations

## Setup

Install the package dependencies in a virtual environment, then export a database URL:

```bash
pip install -e .
export DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5432/spof
```

## Run migrations

Apply the latest schema:

```bash
alembic upgrade head
```

Create a new migration after model changes:

```bash
alembic revision --autogenerate -m "describe change"
```

Autogenerated migrations should be reviewed and edited before use. The initial schema migration in this repo was written and reviewed manually from `V1-schema-design.md`.
